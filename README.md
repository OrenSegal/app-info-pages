# app-info-pages

This repo holds the privacy policy and support pages for Cairn, my Mac podcast app; it is not a portfolio project. The pages are served by GitHub Pages from `main` at [orensegal.github.io/app-info-pages](https://orensegal.github.io/app-info-pages/). The App Store listing links here, so the repo stays public and the page URLs (`privacy.html`, `support.html`) must not change.
